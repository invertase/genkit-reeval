## Genkit

This project uses Genkit for JavaScript.

- Follow the API rules at https://genkit.dev/GENKIT.js.md.
- For a single topic, fetch the page as markdown, for example
  https://genkit.dev/docs/js/flows.md or https://genkit.dev/docs/js/tool-calling.md.
- For the whole SDK in one file, fetch https://genkit.dev/llms-js.txt.
- Do not guess API names. Check the page first.
